# 🧠 Idea del proyecto: Workout Tracker

## 📌 Descripción general

Workout Tracker es una aplicación web fullstack que permite a los usuarios registrar, visualizar y gestionar sus entrenamientos diarios de forma sencilla.

La aplicación está diseñada para ofrecer una experiencia rápida y clara, permitiendo al usuario añadir entrenamientos, visualizar su lista y eliminarlos cuando sea necesario.

---

## 🎯 Problema que resuelve

Muchas personas que entrenan de forma regular no tienen una herramienta simple para registrar sus sesiones de entrenamiento.

Las aplicaciones existentes suelen ser:
- demasiado complejas
- llenas de funcionalidades innecesarias
- difíciles de usar rápidamente

Workout Tracker resuelve este problema proporcionando:
- una interfaz minimalista
- gestión rápida de entrenamientos
- sin necesidad de registro ni configuración

---

## 👤 Usuario objetivo

El usuario objetivo es:

- Personas que entrenan en gimnasio o en casa
- Usuarios que buscan simplicidad
- Principiantes que no necesitan apps complejas
- Usuarios que quieren registrar entrenamientos de forma rápida

---

## ⚙️ Funcionalidades principales

- Crear un entrenamiento
- Visualizar lista de entrenamientos
- Eliminar entrenamientos
- Persistencia en backend mediante API REST

---

## 🔧 Funcionalidades opcionales

- Editar entrenamientos
- Marcar como completado
- Añadir fecha o duración
- Filtrar entrenamientos
- Autenticación de usuario

---

## 🚀 Mejoras futuras

- Base de datos (MongoDB / PostgreSQL)
- Diseño avanzado con Tailwind
- Uso de Context API
- Navegación con React Router
- Deploy en producción

---

## 🧩 Enfoque técnico

- Frontend: React + TypeScript
- Backend: Node.js + Express
- API REST: /api/v1/workouts
- Persistencia: memoria (simulada)

---

## 📌 Conclusión

Este proyecto demuestra el desarrollo de una aplicación fullstack completa, aplicando buenas prácticas y separando correctamente frontend y backend.
