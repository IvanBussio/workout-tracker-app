# 🧠 Metodologías de desarrollo: Agile, Scrum y Kanban

##  ¿Qué es Agile?

Agile es una metodología de desarrollo de software basada en la flexibilidad, la colaboración y la entrega continua de valor.

Su objetivo principal es adaptarse a los cambios y mejorar el producto de forma incremental, en lugar de seguir un plan rígido desde el inicio.

En lugar de desarrollar todo el proyecto de una sola vez, Agile propone dividir el trabajo en pequeñas partes funcionales que se entregan progresivamente.

---

##  Objetivo de Agile

- Adaptarse rápidamente a cambios en los requisitos
- Entregar valor al usuario de forma continua
- Mejorar la comunicación entre el equipo
- Reducir riesgos durante el desarrollo
- Obtener feedback constante del cliente

---

##  ¿Qué es Scrum?

Scrum es un framework dentro de Agile que organiza el trabajo en ciclos llamados *sprints*.

Cada sprint es un periodo corto de tiempo (normalmente entre 1 y 4 semanas) en el que se desarrolla una parte funcional del producto.

---

## 👥 Roles en Scrum

- **Product Owner:** define los requisitos del producto y prioriza el trabajo
- **Scrum Master:** facilita el proceso y elimina obstáculos
- **Equipo de desarrollo:** implementa las funcionalidades

---

##  Conceptos principales de Scrum

- **Sprint:** ciclo de trabajo corto con objetivos definidos
- **Backlog:** lista de tareas o funcionalidades pendientes
- **Sprint Planning:** planificación de tareas para el sprint
- **Daily Scrum:** reunión diaria de seguimiento
- **Sprint Review:** revisión del trabajo realizado
- **Sprint Retrospective:** análisis para mejorar el proceso

---

## 📋 ¿Qué es Kanban?

Kanban es una metodología visual para gestionar tareas de forma continua.

Se basa en un tablero donde las tareas se organizan en columnas que representan el estado del trabajo.

---

##  Cómo se usa Kanban

Un tablero típico tiene columnas como:

- Backlog
- To Do
- In Progress
- Review
- Done

Las tareas se mueven entre columnas a medida que avanzan.

---

##  Diferencias entre Scrum y Kanban

| Scrum | Kanban |
|------|--------|
| Trabajo por sprints | Flujo continuo |
| Roles definidos | No requiere roles específicos |
| Planificación por iteraciones | Sin planificación fija |
| Cambios limitados durante sprint | Cambios en cualquier momento |
| Estructura más rígida | Más flexible |

---

##  ¿Cuándo usar cada metodología?

### Scrum

Se utiliza cuando:
- El proyecto es complejo
- Se necesita planificación estructurada
- Hay un equipo definido
- Se trabaja por entregas periódicas

### Kanban

Se utiliza cuando:
- Se necesita flexibilidad
- El trabajo es continuo
- No hay ciclos definidos
- Se quiere visualizar el flujo de tareas

---

##  Conclusión

Las metodologías Agile, Scrum y Kanban permiten mejorar la organización del desarrollo de software, facilitando la adaptación a cambios y la entrega continua de valor.

En este proyecto se puede aplicar Kanban para organizar tareas y Scrum como referencia para estructurar el trabajo en fases.
