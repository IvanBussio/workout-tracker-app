# Retrospective

## Qué aprendí

Durante este proyecto aprendí a desarrollar una aplicación web utilizando React y TypeScript, organizando el código en componentes y gestionando el estado con hooks como useState y useEffect.

También aprendí a estructurar un proyecto fullstack, aunque finalmente decidí simplificar la arquitectura utilizando LocalStorage en lugar de un backend para facilitar el despliegue.

## Problemas encontrados

Uno de los principales problemas fue la conexión entre frontend y backend, especialmente en la gestión de rutas y errores.

También tuve dificultades con TypeScript al trabajar con archivos JavaScript sin tipos.

## Cómo lo resolví

Decidí simplificar la aplicación eliminando la dependencia del backend y utilizando LocalStorage como sistema de persistencia.

Además, convertí los archivos a TypeScript para evitar errores de tipado.

## Uso de IA

Utilicé IA para resolver errores técnicos, mejorar la estructura del proyecto y entender mejor conceptos como hooks, arquitectura y despliegue.

## Conclusión

Este proyecto me ayudó a entender mejor el desarrollo web moderno y a aplicar buenas prácticas en la organización del código y despliegue de aplicaciones.
